# CRUD React 1

Implementación del Ejercicio 2 del TP1 Parte Individual: Actividad B. El sistema administra registros de clientes con nombre y e-mail.

## Inicio

```bash
npm install
npm run dev
```

Vite mostrará la dirección local en la terminal.

## Operaciones ABM

- `NUEVO REGISTRO`: crea un cliente desde un modal.
- Ícono de edición: modifica el cliente seleccionado.
- Ícono de eliminación: elimina el cliente seleccionado.
- La tabla funciona como consulta/listado de los registros.

Los registros se almacenan en `localStorage` bajo la clave `cad_cliente`, por lo que se conservan al recargar la página en el mismo navegador.
